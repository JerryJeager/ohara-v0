# Ohara

Ohara is an AI-powered website assistant that allows businesses and website owners to deploy a contextual AI chatbot trained on their website content.

The frontend provides:

- Landing page and product showcase
- Google authentication
- Website management dashboard
- Widget configuration and installation
- Indexed page management
- AI assistant setup workflow

Users can add a website, allow Ohara to index its content, and receive an embeddable chat widget that can be integrated into any website with a single script tag.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Features

- Modern dashboard experience
- Website indexing management
- Widget installation flow
- Responsive design
- Embedded AI assistant configuration

The frontend communicates with the Ohara backend to manage websites, monitor indexing status, configure widgets, and provide a streamlined experience for deploying AI-powered website assistants.
